# 旭儿综合网站

修改与2026年5月10号   最终修复

一个功能完整的个人导航网站 + 博客系统，部署在 Cloudflare Pages 上，使用 KV 作为数据库。

## ✨ 功能特性

### 前台功能
- 📝 **博客文章** - 发布、阅读文章，支持分类和标签
- 🔖 **书签导航** - 按分类整理常用网站链接
- 🌓 **深色模式** - 一键切换明暗主题
- 📱 **移动端适配** - 手机/平板自动调整布局
- 🖼️ **封面图** - 文章封面图仅在首页显示，不影响阅读体验
- 🔗 **一键复制** - 书签卡片支持快速复制网址

### 后台管理
- ✏️ **文章管理** - 写文章、编辑、删除、置顶
- 📚 **书签管理** - 添加/编辑/删除书签，支持排序
- 🖼️ **图片管理** - 上传、浏览、删除图片
- ⚙️ **站点设置** - 修改站点标题、Logo、页眉背景等
- 🔑 **修改密码** - 安全修改管理员密码

## 🚀 部署教程

### 1. 创建 KV 命名空间

进入 Cloudflare Dashboard → **Workers 和 Pages** → **KV** → **创建命名空间**

- 名称：`NAV_KV`（必须完全一致）

### 2. 部署到 Pages

1. 进入 Cloudflare Dashboard → **Pages** → **创建项目** → **直接上传**
2. 将以下文件打包成 zip 上传：
   - `_worker.js`（主程序文件）
   - `README.md`（可选）
3. 部署完成后，进入项目设置 → **函数** → **KV 命名空间绑定**
   - 变量名：`NAV_KV`
   - KV 命名空间：选择刚才创建的 `NAV_KV`
4. 重新部署

### 3. 绑定自定义域名（可选）

Pages 项目 → **自定义域** → **设置自定义域** → 按提示添加 DNS 记录

## 📦 KV 数据结构

| Key | 说明 |
|-----|------|
| `sites` | 书签列表 |
| `blog_posts` | 文章列表 |
| `admin_password` | 管理员密码 |
| `site_title` | 站点标题 |
| `site_subtitle` | 站点副标题 |
| `site_logo` | Logo URL |
| `site_logo_link` | Logo 跳转链接 |
| `header_bg` | 页眉背景图 |
| `cn_link` | 国内线路链接 |
| `views:文章ID` | 文章阅读量 |
| `img:文件名` | 上传的图片 |
| `session:token` | 登录会话 |

## 🛠️ 日常使用

### 发布文章

1. 登录后台 `/admin`
2. 点击 **"写新文章"**
3. 填写标题、分类、内容
4. 可选：封面图、标签、摘要、置顶
5. 选择状态（发布/草稿）
6. 点击 **"发布"**

### 管理书签

1. 登录后台 `/admin`
2. 填写网站名称、网址、分类、排序
3. 可选：Logo URL、描述
4. 点击 **"添加书签"**
5. 列表中可编辑或删除

### 上传图片

1. 登录后台 `/admin`
2. 点击右上角 **"图片管理"**
3. 点击 **"上传新图片"**
4. 选择图片上传
5. 点击图片自动复制 URL，可在文章或书签中使用

### 修改站点信息

1. 登录后台 `/admin`
2. 滚动到底部 **"站点设置"**
3. 修改标题、副标题、Logo 等
4. 点击 **"保存设置"**

### 修改密码

1. 登录后台 `/admin`
2. 点击右上角 **"修改密码"**
3. 输入原密码和新密码
4. 确认修改

## 📝 注意事项

1. **KV 绑定名必须为 `NAV_KV`**，区分大小写
2. 图片上传限制 **5MB**，支持 JPEG、PNG、GIF、WebP
3. 书签排序：数字越小越靠前
4. 置顶文章仅在后台标记，首页不显示特殊标识
5. 删除文章或书签时会**自动删除关联的图片**

## ❓ 常见问题

### Q: 首页显示"暂无文章"？
A: 需要先在后台发布文章，并确保状态为"发布"。

### Q: 图片上传失败？
A: 检查图片大小是否超过 5MB，或格式是否为支持的格式。

### Q: 富文本编辑器不显示？
A: 检查网络是否能访问 `cdn.staticfile.org`。

### Q: 忘记管理员密码？
A: 在 Cloudflare KV 中直接修改 `admin_password` 的值。

### Q: 如何备份数据？
A: KV 中的数据可以通过 Cloudflare API 或 Dashboard 手动导出。
